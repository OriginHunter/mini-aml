## MM-DD（周X）

**核心产出**：〔动作 + 产出，一句话 ≤80 字，先写做了什么，再写技术点〕

**工作内容（≤2000 字）**：

> 〔背景：为什么做这件事〕
> 〔过程：具体做了什么，带类名 / 接口名 / 文件路径〕
> 〔结果：可验证的产出，带数字〕

**工时**：Xh

**备注**（选填，写踩坑与根因，答辩素材）：

## 写之前的三个自检

1. 有没有"学习了 / 了解了 / 熟悉了"这类无法验收的词？→ 换成"实现了 X，接口 Y 返回 Z"。
2. 有没有数字？→ 数据量、耗时、接口数、测试用例数，至少一个。
3. 能不能被追问？→ 每一句都要预备"为什么这么做"的答案。
